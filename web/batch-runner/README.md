# Batch Runner

Two batch rendering tools for generating USD preview images in headless Chrome.

## Preview Generator (generate-previews.js)

Renders every USD asset from the curated manifest into 1280×720 PNG previews
using `usd-assets-view.html` as the viewer page. Camera position and clear color
are configurable per asset via the settings JSON.

```bash
# Install dependencies (first time)
npm install

# Render all 263 assets
xvfb-run -a node generate-previews.js --output ./previews

# Render specific assets
node generate-previews.js --assets sphere,cube,CesiumMan

# Skip assets that already have a preview
node generate-previews.js --skip-existing

# Use hardware GPU
xvfb-run -a node generate-previews.js --gpu
```

### Settings

`usd-assets-settings.json` controls camera, clear color, and backend per asset:

```json
{
  "defaults": {
    "camera": { "az": 0.8, "el": 0.35, "fov": 50, "padding": 1.1 },
    "clear": [0.12, 0.12, 0.14, 1.0]
  },
  "categories": {
    "primitives": { "camera": { "dist": 4.0 } },
    "usdz": { "camera": { "az": 2.2, "dist": 4.5 }, "clear": [0.16, 0.18, 0.22, 1.0] }
  },
  "assets": {
    "DamagedHelmet": { "camera": { "az": 1.4, "dist": 3.5 } }
  }
}
```

Resolution is merged: `defaults ← categories[cat] ← assets[id]`.

### Requirements

- Node.js 20+
- Google Chrome or Chromium
- `xvfb-run` for headless environments (CI, servers without display)

### Chrome Setup

See [headless-chrome-setup.md](./headless-chrome-setup.md) for GPU
acceleration, SwiftShader, and Docker configuration.

### npm scripts

| Script | Description |
|--------|-------------|
| `npm run previews` | Render all assets |
| `npm run previews:skip` | Render only missing previews |
| `npm run previews:sphere` | Render just the sphere asset |

## Visual Regression Runner (batch-runner.js)

The original batch runner for visual regression testing. Compares rendered USD
output against reference images using pixelmatch.

```bash
npm run generate -- -i ../js/models -o ./batch-results
npm run validate -- -i ../js/models -o ./batch-results --threshold 2.0
```

## Generator script dependency

Both runners import the asset manifest from `../demo/src/usd-assets-manifest.js`,
which is auto-generated by `../demo/scripts/generate-asset-manifest.js`. To
regenerate:

```bash
USD_ASSETS_DIR=/path/to/usd-wg/assets node ../demo/scripts/generate-asset-manifest.js
```
