TinyUSDZ

A secure, portable, dependency-free USD (Universal Scene Description) library for C++17 — running right in your browser via WebAssembly.

Launch 3D Demo Browse all demos

USDA / USDC / USDZ

Reads and writes ASCII, Crate binary, and zipped USD — no external dependencies.

MaterialX & OpenPBR

MaterialX v1.36–1.39 support, including the OpenPBR Surface shading model.

Animation

SkelAnimation, xformOp timeSamples, and blend shapes for animated scenes.

USD Composition

References, sublayers, payloads, inherits, and variants resolved on the web.

Three.js + WASM

Tydra scene graph converts to Three.js, all running client-side in WebAssembly.

Zero dependencies

Pure C++17 STL core — a ~3.2 MB WASM binary that compresses to ~641 KB with zstd.
