TinyUSDZ Subdivision Surface Demo

Interactive demo showing Catmull-Clark, Loop, and Bilinear subdivision algorithms.

Controls:
  • Mouse: Orbit camera
  • Right Panel: Adjust subdivision levels (0-5)
  • Toggle Wireframe: See mesh topology
  • Select Scheme: Switch between algorithms
Subdivision Schemes:
Catmull-Clark
Smooth quads (C² continuous)
Loop
Smooth triangles (C¹ continuous)
Bilinear
Linear interpolation only
Mesh Statistics:
Vertices: -
Faces: -
Triangles: -
Subdivision Level: -

This demo uses dependency-free subdivision implementation compatible with USD format. All subdivision happens in JavaScript using the same algorithms as the C++ backend.
